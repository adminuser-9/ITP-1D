# Tales of Lanfang Tickets

Run from this folder in PowerShell:

    .\.venv\Scripts\python.exe -m pip install -r requirements.txt
    .\.venv\Scripts\python.exe -m streamlit run app.py

Open http://localhost:8501. Press Ctrl+C in the terminal to stop the server.

If the virtual environment is missing, create it first with an installed Python: python -m venv .venv.

The pricing functions in mylibrary.py currently contain placeholder return values.
